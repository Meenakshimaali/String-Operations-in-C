# String Operation Project in C

This is a simple menu-driven String Operation Project developed using the C programming language. The project performs different string manipulation operations such as converting uppercase and lowercase letters, reversing strings, reversing words, capitalizing letters, and counting character occurrences.

The program is useful for beginners to understand string handling concepts, functions, loops, arrays, pointers, and conditional statements in C programming.

Features included in this project:

- Convert String to Uppercase
- Convert String to Lowercase
- Reverse Complete String
- Reverse Each Word
- Convert First Letter of Each Word to Uppercase
- Convert Last Letter of Each Word to Uppercase
- Count Character Occurrence

Technology Used:
- C Programming Language
- Standard Library Functions
- String Handling Functions

Project File:
- string project.c

How to Run the Program:

Compile the program using:

```bash
gcc "string project.c" -o stringproject
```

Run the program using:

```bash
./stringproject
```
